TutorNote v6 — CRM Calendar

Нові можливості:
1. Перемикання тижнів назад/вперед + кнопка «Сьогодні».
2. Режими календаря День / Тиждень / Місяць.
3. Статуси: Заплановано, Проведено, Скасовано учнем, Скасовано викладачем, Перенесено, Не прийшов.
4. Окреме перенесення заняття зі збереженням старого запису в історії.
5. Абонементи: N занять за суму, автоматичне списання після «Проведено», попередження на 1–2 заняттях.
6. Баланс учня: надходження мінус проведені заняття.
7. Групова модель оплати: за кожного учня або за всю групу.
8. Розширений CRM-профіль учня.
9. Dashboard: заняття, тривалість, очікуваний дохід, борги, неоплачені, абонементи.
10. Розумна зміна регулярного розкладу: лише найближче заняття / усі майбутні / не змінювати.

Дані сумісні з TutorNote v5. Supabase SQL змінювати не потрібно: backup зберігає зашифрований повний стан застосунку.
