TutorNote Secure Cloud — налаштування Supabase
=============================================

ЩО ЦЕ ДАЄ
- Дані залишаються локально на iPhone.
- Після змін TutorNote автоматично створює зашифровану копію в Supabase.
- Вміст резервної копії шифрується на iPhone алгоритмом AES-256-GCM ДО відправлення.
- У Supabase немає відкритих імен учнів, нотаток, занять чи оплат — лише ciphertext.
- Хмарні копії не видаляються автоматично.
- Видалення хмарної копії та відновлення поверх поточних даних потребує PIN адміністратора.
- Фраза відновлення ніколи не надсилається в Supabase.

ВАЖЛИВО
Фраза відновлення — це єдиний спосіб відкрити хмарну копію після втрати/очищення iPhone.
Запишіть її окремо від телефона (наприклад, у менеджері паролів або на папері в безпечному місці).
Якщо забути і пароль Supabase, і фразу відновлення, відновлення даних може бути неможливим.

1. СТВОРІТЬ SUPABASE PROJECT
- Відкрийте https://supabase.com/ та створіть безкоштовний проект.
- Дочекайтеся, поки проект стане Active.

2. СТВОРІТЬ ТАБЛИЦІ Й ЗАХИСТ RLS
- Supabase Dashboard -> SQL Editor -> New query.
- Відкрийте файл supabase-setup.sql з цього пакета.
- Скопіюйте ВЕСЬ SQL і натисніть Run.
- Він створить 2 таблиці та Row Level Security, щоб кожен акаунт бачив лише свої записи.

3. НАЛАШТУЙТЕ AUTH
- Authentication -> URL Configuration.
- Site URL: вкажіть адресу вашого GitHub Pages TutorNote, наприклад
  https://YOURNAME.github.io/TutorNote/
- Email + Password authentication має бути увімкнена.
- Email confirmation можна залишити увімкненою. Після реєстрації підтвердіть email і потім увійдіть у TutorNote.

4. ВІЗЬМІТЬ PROJECT URL І PUBLISHABLE KEY
- Supabase Dashboard -> Settings -> API Keys (або Integrations -> Data API).
- Скопіюйте Project URL.
- Скопіюйте Publishable key (sb_publishable_...).
  Якщо проект ще показує legacy anon key — його теж можна використати.
- НІКОЛИ не вставляйте secret / service_role key у TutorNote.

5. ПІДКЛЮЧІТЬ У TUTORNOTE
- TutorNote -> Ще -> Cloud Backup.
- 1. Налаштувати Supabase -> вставте Project URL і Publishable/anon key.
- 2. Увійти / зареєструватися -> створіть або введіть email + пароль.
- 3. Налаштувати ключ -> створіть фразу відновлення мінімум 12 символів.
- Запишіть фразу відновлення в надійному місці.
- Натисніть "Створити зашифровану копію зараз".

6. АВТОМАТИЧНІ КОПІЇ
Після налаштування TutorNote автоматично ставить хмарну копію в чергу після кожної зміни.
Для економії запитів синхронізація дебаунситься і виконується не частіше приблизно одного разу на 30 секунд.
Якщо інтернету немає, TutorNote зберігає позначку pending і повторює копію після повернення мережі.
Хмарні копії append-only: старі версії не видаляються автоматично.

7. ВІДНОВЛЕННЯ НА НОВОМУ IPHONE
- Встановіть TutorNote з GitHub Pages.
- Ще -> Cloud Backup -> налаштуйте той самий Supabase Project URL + Publishable key.
- Увійдіть у той самий email/password.
- Введіть фразу відновлення.
- Відкрийте "Хмарні резервні копії" -> Відновити.

КРИПТОГРАФІЯ
- Backup content: AES-256-GCM, випадковий IV для кожної копії.
- Master backup key: випадкові 256 біт.
- Master key у хмарі зберігається лише у wrapped/encrypted вигляді.
- Recovery phrase -> PBKDF2-HMAC-SHA-256, 250,000 ітерацій -> AES-256-GCM wrapping key.
- Для перевірки цілісності кожної копії зберігається SHA-256 ciphertext payload plaintext hash; він не розкриває вміст резервної копії.

ПРИМІТКА ПРО "АВТОМАТИЧНО"
PWA на iPhone не може працювати у фоні постійно як серверний процес. Автокопія створюється, коли TutorNote відкритий/активний і після змін. Якщо застосунок повністю закритий, iOS не гарантує фоновий запуск JavaScript.
