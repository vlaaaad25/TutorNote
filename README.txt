TutorNote v6 — CRM для репетитора

ОСНОВНЕ
- Учні та групи з регулярним розкладом.
- Календар: День / Тиждень / Місяць, перемикання вперед/назад, кнопка «Сьогодні».
- Статуси занять: Заплановано, Проведено, Скасовано учнем, Скасовано викладачем, Перенесено, Не прийшов.
- Перенесення заняття зі збереженням старої події в історії.
- Абонементи на N занять з автоматичним списанням після статусу «Проведено».
- Баланс учня: оплати мінус проведені заняття.
- Групова оплата: за кожного учня або фіксовано за всю групу.
- CRM-профіль учня: наступне заняття, розклад, групи, проведені, пропуски, остання оплата, баланс, дохід, примітки, абонементи.
- Dashboard: заняття сьогодні, тривалість, очікуваний дохід, неоплачені, борги, абонементи що закінчуються.
- Розумна зміна регулярного розкладу: лише найближче заняття / усі майбутні / залишити графік без змін.

ЗАХИСТ ДАНИХ
- Локальне збереження на iPhone.
- До 50 автоматичних локальних резервних копій.
- Кошик та PIN адміністратора.
- Зашифрований Cloud Backup через Supabase (AES-256-GCM).
- JSON export/import.

IPHONE / GITHUB PAGES
1. Завантажте всі файли з архіву в корінь GitHub-репозиторію TutorNote.
2. GitHub Pages: main → /(root).
3. Відкрийте сайт у Safari.
4. Поділитися → На початковий екран → Додати.
5. Після оновлення коду інколи потрібно один раз відкрити сайт у Safari та перезапустити PWA, щоб новий Service Worker замінив кеш.

СУМІСНІСТЬ
Дані TutorNote v5 зберігаються. Нові поля додаються без очищення старої бази.
Supabase SQL для v6 змінювати не потрібно.
